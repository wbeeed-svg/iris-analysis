\# Iris Dataset Analysis



\## Project Description

This project analyzes the Iris dataset using Python, Pandas, and Matplotlib in Jupyter Notebook.



\## Dataset

The dataset contains 150 observations and 5 columns, including four numerical measurements and one species column.



The three Iris species are Setosa, Versicolor, and Virginica.



\## Project Features

\- Data loading and exploration

\- Missing values and duplicate detection

\- Statistical analysis

\- Data filtering and sorting

\- Data visualization using bar charts, scatter plots, and a correlation heatmap

\- Exporting analysis results to CSV files



\## How to Run

1\. Install uv and Python.

2\. Open a terminal in the project folder.

3\. Run `uv sync` to install project dependencies.

4\. Run `uv run jupyter notebook`.

5\. Open `iris\_analysis.ipynb` and run all cells.



\## Output Files

\- `output/species\_summary.csv` — Average measurements for each species.

\- `output/filtered\_iris.csv` — Flowers with sepal length greater than 6 cm.



\## Conclusion

The Iris dataset is balanced and contains no missing values. Petal length and petal width are useful for distinguishing between different Iris species.
